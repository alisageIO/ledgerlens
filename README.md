# LedgerLens

A personal finance app: idempotent CSV statement import, auto-categorised transactions,
budgets/pots/recurring bills, and an "explain my month" summary generated by a bounded
LLM tool-loop grounded in your real numbers.

Full product/technical detail lives in [docs/](./docs) — start with
[docs/PRD.md](./docs/PRD.md) (what/why) and [docs/TRD.md](./docs/TRD.md) (how).
[docs/implementation-guide.md](./docs/implementation-guide.md) maps each TRD section to
concrete modules in this repo.

## Repo layout

This is a monorepo with two independently-deployed services:

| Path | What |
| --- | --- |
| [backend/](./backend) | FastAPI service — API layer, domain logic, ML categoriser, agent loop (Python, `uv`) |
| [web/](./web) | Next.js app (TypeScript, `pnpm`) |
| [docs/](./docs) | PRD, TRD, epics, roadmap, tickets |

## Quickstart

```bash
cp backend/.env.example backend/.env
cp web/.env.example web/.env.local
make dev   # docker compose up --build — web, api, db, no manual steps beyond this
```

- API: http://localhost:8000 (health check at `/health`, docs at `/docs`)
- Web: http://localhost:3000

Running services outside Docker:

```bash
make backend-install && make backend-test   # backend: uv sync / pytest
make web-install && make web-build          # web: pnpm install / build
```

Run `make help` for the full list of targets.
